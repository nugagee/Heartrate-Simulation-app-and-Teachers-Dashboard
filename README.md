# Heart Rate Simulation App

The Heart Rate Simulation App is a Python-based application designed to simulate heart rate data for testing, analysis, and development purposes. It generates realistic heart rate patterns and provides tools for visualization and data export, making it ideal for developers and researchers working on health-related projects.

## Features

- **Heart Rate Simulation**: Generate realistic heart rate data for various scenarios.
- **Data Visualization**: View heart rate patterns in real-time using graphical plots.
- **Data Export**: Save simulated data in formats like CSV for further analysis.
- **Customizable Parameters**: Adjust simulation settings such as heart rate range and duration.
